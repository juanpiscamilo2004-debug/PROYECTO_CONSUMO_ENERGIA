# Datos

Este proyecto utiliza el dataset **Appliances Energy Prediction** del UCI Machine Learning Repository.

Archivo utilizado:

energydata_complete.csv

Fuente canónica:

UCI Machine Learning Repository - Appliances Energy Prediction

DOI:

10.24432/C5VC8G

## Instrucciones

1. Descargar el dataset desde la fuente oficial de UCI.
2. Extraer el archivo energydata_complete.csv.
3. Para ejecutar los notebooks en Google Colab, subir manualmente el CSV a la sesión.
4. Los notebooks esperan el archivo en la ruta:

/content/energydata_complete.csv

El dataset no se incluye directamente en este repositorio. Se conserva la referencia a la fuente original para mantener trazabilidad y reproducibilidad.
